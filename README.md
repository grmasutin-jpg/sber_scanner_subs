# Сбер Финансы — аудит выписки и подписок v4

Прототип анализирует банковские выписки, проверяет распознанные строки и ищет подписки/регулярные платежи. Полная история транзакций не показывается в интерфейсе и не попадает в JSON-экспорт: строки используются только внутри текущего анализа для точных итогов, графиков и поиска регулярности.

## Что улучшено в v4

- Боковое меню стало иерархическим: глава «Анализ выписки», глава «Аналитика и AI» и глава «Справка» раскрывают свои подглавы.
- Верхняя панель теперь полностью непрозрачная. Удалена декоративная зелёная полоса прокрутки.
- У поля поиска осталась только лупа внутри поля — визуальная подсказка `K` удалена. Горячая клавиша `Ctrl/Cmd + K` при этом продолжает работать.
- Поддержка файлов расширена: **PDF, CSV, TSV, TXT, JSON, OFX, QFX, XLS, XLSX**.
- Для текстовых файлов добавлено определение UTF‑8 / Windows‑1251 и разделителя; Excel читает все листы; PDF пытается склеивать многострочные операции перед разбором.
- Лимит файла — 35 МБ с понятной ошибкой для пустых/неподдерживаемых файлов.

## Более сильный поиск подписок

Локальный алгоритм теперь оценивает не только одинаковую сумму. Для каждого кандидата рассчитываются:

- даты и интервалы между списаниями;
- медианный интервал и разброс интервалов;
- стабильность дня месяца;
- медианная, минимальная и максимальная сумма;
- изменение цены в процентах;
- merchant/название сервиса;
- явные признаки `subscription`, «подписка», «автосписание», «абонентская плата», «тариф», membership/premium и т.п.;
- категория операции и локальные veto для обычных покупок.

Изменение цены больше не ломает поиск: подписка может подорожать, иметь скидку, пробный период, налог или конвертацию валюты. Одно списание допускается как кандидат только при прямом текстовом признаке регулярного платежа.

## Двухпроходная AI-проверка

При наличии `DEEPSEEK_API_KEY` используется `deepseek-v4-pro` с thinking и `reasoning_effort=max`.

1. Первый AI-проход проверяет **каждый** локальный кандидат: все даты, суммы, merchant, описания, цикл, изменение цены и тип регулярного платежа.
2. Неоднозначные случаи автоматически уходят на второй независимый проход-арбитраж.
3. Сервер не принимает новые `candidate_id`, которых не было во входных данных.
4. Название от AI принимается только если оно поддерживается merchant/description из evidence.
5. Повторяющиеся рестораны, продукты, маркетплейсы, такси, переводы людям и обычные покупки не превращаются в подписки только из-за периодичности.

AI возвращает дополнительное понимание: тип подписки/регулярного счёта, цикл списания, уверенность, факт изменения цены и объяснение на основе evidence.

## Аудит выписки

- Каждая строка проходит локальную проверку даты, суммы, merchant и описания.
- Денежные итоги складываются в копейках.
- Одинаковые дата + сумма + описание не удаляются автоматически: реальные повторные операции сохраняются, возможные дубли только помечаются.
- При подключённом DeepSeek строки небольшими пакетами сверяются с `raw_source`.
- AI-коррекции даты/суммы/направления применяются только при высокой уверенности и после серверной проверки, что значение реально присутствует в исходной строке.

## Запуск

```bash
npm install
cp .env.example .env
# вставьте DEEPSEEK_API_KEY в .env
npm start
```

Откройте `http://localhost:3000`.

Без API-ключа остаются доступны парсинг, аудит, аналитика и консервативный локальный поиск регулярных платежей.

## Переменные окружения

```env
DEEPSEEK_API_KEY=...
DEEPSEEK_MODEL=deepseek-v4-pro
DEEPSEEK_REASONING_EFFORT=max
PORT=3000
```

## Ограничение PDF

PDF с текстовым слоем разбираются по координатам и строкам. Для сканов/фотографий без текстового слоя по-прежнему нужен OCR или отдельная серверная обработка изображений.
